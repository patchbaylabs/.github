## Who we are

Patchbay Labs builds software for the people who run live production audio — the A2 in
the wings, the RF tech at the booth, the engineer at the desk. Our tools are written for
the way shows actually run: long calls, no second takes, and failures that show up
mid-scene rather than in a test rig.

We work on the parts of the job that existing gear leaves uncovered. Console
manufacturers build consoles; receiver manufacturers build receivers. The gap between
them — knowing which of forty mics is about to fail, and proving it after the fact — is
where we spend our time.

## What we care about

- **Built with practitioners.** Features come from show reports and shop notes, not
  feature-parity checklists.
- **Open source by default.** Our tools ship under permissive or copyleft licenses. If
  you run it, you can read it, patch it, and keep running it.
- **Native and fast.** Real-time audio work is unforgiving. We write in Rust and target
  the platforms production teams already carry.
- **Offline-first.** Venues have bad networks and locked-down VLANs. Nothing we build
  should need the internet to do its job.
